# NXRTHXRN Website — Front-end source

## Run locally
1. Install Node.js (18+).
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Structure
- `src/components/` — each page section and interactive component in its own file.
- `src/data/releases.js` — release metadata and artwork mapping.
- `src/styles/` — global, layout and component styles.
- `public/assets/` — the five supplied original cover images.

## Before launch
- Add official Spotify / Apple Music URLs when available.
- Replace `—` release years with confirmed dates.
- Confirm all public-facing biography details.
- Check the Instagram URL and other social destinations.
- Connect any backend features separately; this project is a front-end visual prototype.
